# power-bi-analiza-prodaje
Dashboard za analizu podataka
Ovaj projekat predstavlja dashboard izrađen u okviru praktične vježbe na času, sa ciljem primjene osnovnih principa analize i vizuelizacije podataka.
Dashboard omogućava prikaz, obradu i izračunavanje različitih podataka, kao i pregled rezultata na jasan i pregledan način.

Prikaz dashboard
Funkcionalnosti
Izračunavanje i analiza podataka
Prikaz ključnih rezultata
Izračunavanje osnovnih statističkih vrijednosti
Vizuelizacija podataka
Pregledan prikaz rezultata

Cilj projekta
Cilj projekta bio je da kroz praktičnu vježbu primijenimo znanje iz oblasti rada sa podacima, izvršimo različite proračune i rezultate predstavimo pomoću dashboarda.

Kroz ovaj projekat vježbali smo obradu podataka, njihovu analizu i vizuelni prikaz rezultata.
